# World Countries Data Visualization

A powerful and interactive web application that allows users to explore data about all countries in the world based on name, capital city, or spoken languages. This project also includes visual representations of global population and language statistics using dynamic charts and bar graphs.

## 🚀 Features

- **Search Functionality**: Instantly filter countries by:
  - Name
  - Capital
  - Languages spoken

- **Country Display**:
  - Country name
  - Capital city
  - Official languages
  - Population
  - National flag

- **Sorting Options**:
  - Sort by **name**, **capital**, or **population**
  - Dynamic sorting based on selected criteria

- **Data Visualization**:
  - Countries by **population**
  - Most spoken **languages**
  - Responsive and animated bar charts for visual clarity

-  **Live Search Feedback**:
  - Real-time update of displayed countries as you type
  - Instant feedback on number of matches

## How It Works

1. **Input Handling**: When the user types into the search bar, the app filters countries based on the selected criteria.
2. **Sorting**: You can click buttons to sort by name, capital, or population.
3. **Visualization Toggle**: Clicking the chart button scrolls down to a section where population or language data is represented in a chart format.
4. **Interactive UI**: The interface responds dynamically to user input and reflects changes immediately.
## Chart Features

- Bar charts represent:
  - **Population** distribution among most populated countries
  - **Language** usage frequency among countries
- Width of bars is proportional to values
- Country names and values are displayed alongside each bar
